# H2gO: Clean Water Challenge (React)

An interactive educational clean water planner game built with React, TypeScript, and Vite, inspired by charity: water's global clean water mission.

## Features
- **Community Challenges**: Roleplay as a clean water planner evaluating 4 distinct regional scenarios (Drylands, Mountain Valley, Coastal Plain, and Rainforest).
- **Decision Making**: Choose between 4 viable water solutions (Community well, Pipeline, Rainwater collection, and Filtration system).
- **Educational Feedback**: Instant contextual feedback explaining why the chosen water intervention fits or doesn't fit, complete with real-world clean water facts.
- **Scoring & Timer**: 60-second countdown challenge with point awards (+10 points for correct solutions, -5 points penalty with animated visual indicator).
- **Celebration & Results**: End screen summary with calculated communities helped, personalized performance feedback, and festive confetti animation for high scores.
- **Responsive Layout**: Designed for seamless play across desktop, tablet, and mobile screens.

## Tech Stack
- **Framework**: React 18 with TypeScript
- **Tooling**: Vite
- **Styling**: Responsive custom CSS preserving the charity: water brand aesthetic
